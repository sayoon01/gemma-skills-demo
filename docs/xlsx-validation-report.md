# Gemma 기반 xlsx 스킬 적용 검증 결과

## 1. 목적

공개 Agent Skills 형식의 xlsx 스킬을 다운로드하고,
Claude Code 없이 Gemma와 Python 실행 프로그램을 이용하여
엑셀 생성 작업에 적용할 수 있는지 검증한다.

## 2. 사용 구성

| 항목 | 내용 |
|---|---|
| 모델 | gemma4:31b |
| 모델 연결 | Ollama 호환 API |
| 스킬 | anthropics/skills의 xlsx |
| 스킬 저장소 커밋 | 41bbe19d1a1a7eaab5e7bb9050a417e5c6cffc8f |
| SKILL.md SHA-256 | 6712b39718fe815054abca9c3ee72f989613e6f771c8a5c58f30a65a6c905622 |
| Python | 3.14.2 |
| 실행 환경 | Linux aarch64 |
| 파일 생성 | openpyxl |
| 수식 재계산 | 원본 스킬의 recalc.py와 LibreOffice 24.2.7.2 |
| 텍스트 변환 | markitdown 0.1.7 |

## 3. 실행 방식

1. 스킬 로더가 xlsx의 기본 메타데이터를 검사한다.
2. 선택한 SKILL.md의 본문을 Gemma에 전달한다.
3. Gemma에 매출 엑셀 생성 도구의 인터페이스를 제공한다.
4. Gemma가 사용자 데이터를 도구 인자로 전달한다.
5. 실행 프로그램이 원본 입력과 도구 인자의 일치 여부를 검사한다.
6. Python 도구가 수식과 차트를 포함한 엑셀을 생성한다.
7. 원본 recalc.py로 수식을 재계산한다.
8. 계산값, 수식 보존, 입력값, 차트 존재를 검사한다.
9. markitdown으로 실제 엑셀을 읽는다.
10. 실행 결과를 Gemma에 전달하고 최종 답변을 받는다.

공개 xlsx 스킬 지침을 Gemma에 전달하고, Gemma가 사전 구현된
매출 엑셀 도구를 호출하여 파일 생성·수식 재계산·자동 검증을
