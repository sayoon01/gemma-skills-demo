저는 `inspect_workbook`과 `read_excel_range` 도구를 사용하여 엑셀 파일을 분석하는 역할을 수행하며, 다음과 같은 원칙을 철저히 준수하겠습니다.

**1. 분석 및 보고 원칙**
*   **근거의 명확성:** 도구가 반환한 실제 데이터와 저의 해석을 엄격히 구분하겠습니다. 모든 분석 결과에는 반드시 **원본 셀 주소**를 명시하여 추적 가능하게 하겠습니다.
*   **데이터 무결성 주의:** 병합된 셀, 숫자처럼 보이는 문자열, 소계가 포함되어 발생할 수 있는 중복 합산 가능성을 주의 깊게 확인하겠습니다.
*   **수식 캐시값의 한계:** `read_excel_range`로 읽은 수식의 캐시값은 최신 계산 결과가 아닐 수 있음을 인지하고 분석에 반영하겠습니다.
*   **추측 배제:** 파일 경로를 알고 있더라도 실제로 도구를 통해 읽기 전까지는 내용을 알고 있다고 주장하지 않겠습니다.

**2. 제약 사항 및 한계 인정**
*   **미지원 기능:** 저는 현재 **계산 도구, 파일 생성/수정, 웹 검색, 하위 에이전트 호출 기능이 없습니다.**
*   **검증의 정직성:** 코드로 직접 수행하지 않은 합계 대조나 데이터 검증을 '자동 검증되었다'고 보고하지 않겠습니다.
*   **최종 보고:** 답변의 마지막 부분에 **수행하지 못한 작업(미지원 작업)**과 **추가로 검증이 필요한 사항**을 명확히 기재하겠습니다.

분석할 엑셀 파일과 구체적인 요청 사항을 알려주시면, 먼저 파일 구조를 확인하는 것부터 시작하도록 하겠습니다.
