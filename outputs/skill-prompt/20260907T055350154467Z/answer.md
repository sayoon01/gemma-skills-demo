제시해주신 요구사항을 바탕으로 `xlsx` 스킬 가이드라인을 준수한 엑셀 파일 생성 계획을 다음과 같이 작성하였습니다.

### 1. 데이터 구조 및 설계
*   **시트 구성**: 단일 시트 (예: `Monthly_Sales`)
*   **표 구성**:
    *   **열(Column)**: 월, 수량, 단가, 금액
    *   **행(Row)**: 1월, 2월, 3월, 합계
*   **서식**: 
    *   **폰트**: Arial (전문적인 폰트 적용)
    *   **색상**: 입력값(수량, 단가)은 파란색, 수식 결과값은 검정색으로 설정하여 구분

### 2. 사용할 수식 (Hardcoded 결과 금지)
결과값을 직접 입력하지 않고, 엑셀 수식을 사용하여 데이터 변경 시 자동 계산되도록 설정합니다.
*   **행별 금액**: `=[수량셀] * [단가셀]` (예: `D2` 셀에 `=B2*C2`)
*   **총합**: `SUM` 함수 사용 (예: `D5` 셀에 `=SUM(D2:D4)`)
*   **차트**: `openpyxl.chart.BarChart`를 사용하여 '월'을 X축으로, '금액'을 Y축으로 하는 막대그래프 생성

### 3. 재계산 방법 (Recalculation)
`openpyxl`은 수식의 결과값을 캐싱하지 않으므로, 파일 생성 후 반드시 다음 과정을 거칩니다.
*   **실행 명령**: `python scripts/recalc.py output.xlsx`
*   **목적**: LibreOffice를 통해 수식을 실제로 계산하여 파일에 결과값을 기록하고, 수식 오류 여부를 확인합니다.

### 4. 검증 항목 (Verification)
파일 배포 전 다음 사항을 엄격히 체크합니다.
*   **수식 오류 확인**: `recalc.py` 실행 결과 JSON에서 `status: "success"` 및 `total_errors: 0`인지 확인합니다.
*   **함수 호환성**: LibreOffice에서 인식하지 못하는 최신 함수(XLOOKUP 등) 대신 표준 함수(`SUM`)만 사용했는지 확인합니다.
*   **데이터 일치성**: 
    *   1월: $10 \times 1,000 = 10,000$
    *   2월: $20 \times 1,500 = 30,000$
    *   3월: $15 \times 2,000 = 30,000$
    *   총합: $70,000$ 이 정확히 계산되는지 검증합니다.
*   **서식 준수**: 폰트(Arial) 및 입력값 색상(파란색)이 적용되었는지 확인합니다.
